# 🏧 ATM Simulator Web App

A modern and interactive web-based ATM Simulator that demonstrates basic banking operations, including balance enquiry, cash withdrawal, deposits, money transfers, and transaction history.

## 🌐 Live Demo

🔗 **Live Website:** https://atm-simulator-web-app.vercel.app/

## 📌 About the Project

The ATM Simulator is a web application developed to simulate the basic functionality of an Automated Teller Machine (ATM). It provides a user-friendly interface where users can log in and perform simulated banking operations.

The main purpose of this project is to understand ATM workflows, transaction processing, input validation, and web application development.

## ✨ Features

- 🔐 User Login and Authentication
- 💳 Card Number and PIN Interface
- 📊 Account Balance Enquiry
- 💸 Cash Withdrawal
- 💰 Cash Deposit
- 🔄 Money Transfer Simulation
- 📜 Transaction History
- 🔑 Change PIN
- 🚪 Secure Logout Interface
- 📱 Responsive User Interface

*Features depend on the functionality implemented in the deployed version.*

## ⚙️ How It Works

1. Open the ATM Simulator website.
2. Log in using the demo credentials, if provided.
3. Access the ATM dashboard.
4. Select an available operation.
5. Enter the required amount or details.
6. View the transaction result and updated balance.
7. Check transaction history and log out.
